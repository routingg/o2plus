[페르소나 10종 정의] 
 
P01. 제주 첫 방문 20대 커플 
여행 조건: 2박3일 / 제주시내 숙박 / 렌터카 / 커플 
관심사: 자연·사진 
여행 속도: 보통 
제주에 처음 방문하기 때문에 제주를 대표하는 풍경을 놓치고 싶지는 않지만, 유명 관광지를 무작정 많이 방문하는 일정은 원하지 않는다. 
따라서 대표적인 제주 풍경 + 사진 + 데이트 경험을 중심으로 구성한다. 
코스: 
1일차: 도두봉 → 자매국수 → 이호테우해변 → 한담해안산책로 → 애월 저녁 
2일차: 협재해수욕장 → 한림공원 → 한림 점심 → 오설록 → 금오름 
3일차: 동문시장 → 용두암 → 공항 
 
 
P02. 제주 3번째 방문 30대 커플 
여행 조건: 3박4일 / 애월·한림 숙박 / 렌터카 
관심사: 로컬·휴식 
여행 속도: 느림 
유명 관광지는 이미 경험했기 때문에 새로운 제주를 찾는다. 관광객이 몰리는 장소보다 동네, 산책, 오래 머무를 수 있는 장소를 선호한다. 
핵심 추천 기준은 로컬성 + 조용함 + 장기 체류다. 
코스: 
1일차: 제주시 원도심 점심 → 제주목관아 → 탑동·산지천 산책 → 애월 숙소 휴식 
2일차: 저지오름 → 저지리·한경 점심 → 제주현대미술관 → 신창풍차해안도로 
3일차: 모슬포 산책 → 모슬포 점심 → 송악산 둘레길 → 사계해안 
4일차: 한림읍 동네 산책 → 한림 점심 → 도두동 해안 → 공항 
코스 의미: 
첫 방문객에게 보여주는 제주가 아니라 재방문객이 새로운 제주를 발견하는 과정으로 설계한다. 
 
 
P03. 20대 친구 3명 
여행 조건: 2박3일 / 애월·한림 숙박 / 렌터카 
관심사: 먹거리·사진 
여행 속도: 빠름 
짧은 일정 안에 맛집, 카페, 사진을 모두 경험하고 싶어 한다. 
따라서 한 장소에 오래 머무르기보다는 먹거리 + 사진 + 활기 있는 일정을 만든다. 
코스: 
1일차: 도두 무지개해안도로 → 애월 점심 → 한담해안산책로 → 애월 카페 → 협재해수욕장 → 한림 저녁 
2일차: 오설록 → 산방산·용머리해안 → 사계 점심 → 카멜리아힐 → 동문시장 
 
 
P04. 초등학생 자녀 가족 
여행 조건: 3박4일 / 서귀포·중문 숙박 / 렌터카 
관심사: 체험·자연 
여행 속도: 보통 
아이만 즐겁거나 부모만 즐거운 여행이 되지 않는 것이 중요하다. 
따라서 체험 + 교육 + 자연 + 가족 편의를 함께 고려한다. 
코스: 
1일차: 중문 점심 → 여미지식물원 → 중문색달해변 → 숙소 휴식 
2일차: 제주항공우주박물관 → 안덕 점심 → 오설록 → 신화테마파크 권역 
3일차: 천지연폭포 → 서귀포매일올레시장 → 쇠소깍 
4일차: 휴애리 → 남원 점심 → 이동 
 
 
P05. 4세 아이 동반 가족 
여행 조건: 2박3일 / 조천·구좌 숙박 / 렌터카 
관심사: 자연·휴식 
여행 속도: 느림 
관광지의 유명도보다 낮잠, 화장실, 짧은 이동거리, 실내 대안이 훨씬 중요하다. 
코스: 
1일차: 함덕 점심 → 함덕해수욕장 → 숙소 체크인·낮잠 → 조천 해안 산책 → 숙소 인근 저녁 
2일차: 아쿠아플라넷 → 성산 점심 → 광치기해변 → 세화해변 → 숙소 휴식 
3일차: 비자림 → 구좌 점심 → 공항 
여기서 중요한 것은 ‘숙소 낮잠’도 하나의 여행 슬롯으로 본다는 것이다. 
 
 
P06. 60대 부모님 동반 가족 
여행 조건: 3박4일 / 서귀포·중문 숙박 / 렌터카 
관심사: 자연·먹거리 
여행 속도: 느림 
경사와 장거리 보행을 줄이면서도 제주다운 풍경과 음식을 충분히 경험하는 것이 목표다. 
코스: 
1일차: 중문 향토음식 → 주상절리대 → 카페 → 숙소 휴식 
2일차: 산방산 권역 → 사계해안 → 모슬포 점심 → 오설록 
3일차: 천지연폭포 → 서귀포매일올레시장 → 정방폭포 권역 
4일차: 약천사 → 중문 점심 → 공항 
추천 기준은 저강도 + 경관 + 향토음식이다. 
 
 
P07. 혼자 온 30대 여행자 
여행 조건: 2박3일 / 제주시내 숙박 / 렌터카 
관심사: 문화·산책 
여행 속도: 느림 
혼자 있어도 어색하지 않고, 관광지를 소비하기보다는 생각하고 걷는 시간을 중요하게 생각한다. 
코스: 
1일차: 원도심 혼밥 → 제주목관아 → 관덕정·원도심 골목 → 탑동 산책 → 동문시장 
2일차: 사려니숲길 → 조천 점심 → 국립제주박물관 → 용연·용두암 산책 
핵심 키워드는 혼행 + 산책 + 문화다. 
 
 
P08. 자연 중심 액티브 여행자 
여행 조건: 3박4일 / 성산·표선 숙박 / 렌터카 / 친구 
관심사: 자연 
여행 속도: 빠름 
카페나 쇼핑보다는 오름, 숲, 바다를 최대한 많이 경험하고 싶어 한다. 
코스: 
1일차: 사려니숲길 → 표선 점심 → 따라비오름 → 표선해수욕장 
2일차: 성산일출봉 → 광치기해변 → 성산 점심 → 섭지코지 → 종달리 해안도로 
3일차: 다랑쉬오름 → 구좌 점심 → 비자림 
4일차: 함덕 서우봉 → 공항 
핵심은 오름 + 숲 + 해안이다. 
 
 
P09. 먹으러 제주 오는 재방문객 
여행 조건: 2박3일 / 제주시내 숙박 / 렌터카 / 친구 
관심사: 먹거리 
여행 속도: 보통 
관광지보다 제주 식재료와 시장, 노포, 동네 음식에 관심이 많다. 
코스: 
1일차: 동문시장 → 고기국수 → 원도심 산책 → 제주식 빵·카페 → 돼지고기 저녁 
2일차: 한림민속오일시장 → 한림·한경 점심 → 신창 해안 산책 → 모슬포 간식 → 모슬포 해산물 저녁 
3일차: 서귀포매일올레시장 → 서귀포 향토음식 → 공항 
핵심은 향토음식 + 시장 + 노포다. 
 
 
P10. 아무것도 많이 하고 싶지 않은 커플 
여행 조건: 3박4일 / 대정·안덕 숙박 / 렌터카 
관심사: 휴식 
여행 속도: 매우 느림 
관광지 체크리스트를 채우는 여행보다 한 지역에서 오래 머물고 싶어 한다. 
코스: 
1일차: 안덕·사계 점심 → 숙소 체크인·휴식 → 사계해안 일몰 
2일차: 산방산 산책 → 사계 점심 → 카페·멍때리기 → 송악산 해안 산책 
3일차: 모슬포 산책 → 모슬포 점심 → 숙소 휴식 → 대정 저녁 
4일차: 오설록 → 공항 방향 점심 → 공항 
여기서는 ‘아무것도 하지 않는 시간’ 자체가 추천 콘텐츠다.
